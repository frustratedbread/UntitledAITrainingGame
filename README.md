# UntitledAITrainingGame

I’m making a game where you can train your own neural network-based AI and let it fight in an arena. The core gameplay is similar to that of auto-battler games like Totally Accurate Battle Simulator, but with battlers controlled by code-based AI, human players, or neural network-based AI.

*In the following text, I will use “code” to represent code-based AI and “AI” to represent neural-network-based AI.

## What is this game

In this game, you can:
- Design game characters controlled by code, AI, or human players.
- Put characters in playgrounds (maps) to fight.
- Train an AI for your characters.

Then, code-controlled characters, AI-controlled characters, and characters you control yourself can fight in the same playground. Imagine all possibilities.

Language support: English, 简体中文

## State of the game
The game is still at a very early, unpolished stage, but it is more or less playable, with quite a few concepts already in place. As there aren’t many similar games on the market, I initially built it as an “editor” with a lot of freedom, but it is less intuitive, less goal-oriented, and offers less positive feedback.

Audio is, unfortunately, not ready to be published. So, no sound effects for now :(

I would really appreciate it if you could give it a try and offer suggestions for future development (or whether I should give up). However, I have only tested it myself, without formal QA, so do expect bugs, especially if you decide to train an AI. Apologies in advance for any trouble it may cause.
